# Product Explorer

Product Explorer is a simple web application that helps users browse products and find what they need. It includes product search, category filtering, and price sorting.

## Technologies Used

=> React  
=> TypeScript  
=> CSS  
=> Vite  

## Features

=> View products with images, names, prices, and categories.  
=> Search products by name.  
=> Filter products by category.  
=> Sort products from lowest to highest price.  
=> Responsive layout for mobile and desktop.  
=> Display a message when no products are found.  

## How to Run

1. Clone or download this project.
2. Open the project folder in VS Code.
3. Install the required packages:
 
   npm install
  

4. Start the application:


   npm run dev
  

5. Open the local URL shown in the terminal.
